## 本版研究更新

- 以OSIRIS、PAPlace、DaVinci、PARoute2補強性能導引配置繞線、資料集與閉迴路方法的比較，重寫研究創新定位。
- 以GRAIN建立設計意圖及移植驗證對照；以LiDAR 3.0納入波導與金屬路由的共同限制。
- 將動態IR drop、ECO後特徵、模型漏報與完整PDN重驗納入既有實驗。
- 補充4nm 12b／16GS/s ADC、2nm低電壓SRAM，以及工作負載與3D光子熱估測研究。
- PIC原12組情境細分為四種幾何方案乘三種等總功率分布；保持原兩年期核心範圍與完整驗證原則。

## 文獻計數與證據

原[1]–[50]保留編號及v7查證紀錄，新增[51]–[62]均為2025–2026年正式發表。全部62篇含61篇正式研究與1篇既有預印本，其中54篇屬2023–2026年。OSIRIS採ICLR 2026、LiDAR 3.0採ISPD 2026，對應預印本不重複計數；IMAPSource熱模型論文依出版者採2025年。官方公告與repo資料另列，不計入62篇。

文獻對照表分列全文、作者版本、摘要及書目等查證層級；只有摘要的研究不推定其規則與量化效益。130nm、40nm及數位設計資料不當作4nm類比實測證據。新增資料為文獻連結及研究整合，未在repo再散布所檢索論文的全文。

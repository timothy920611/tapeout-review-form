## 來源與共用索引

v1～v6來自提供者上傳的 `09_計畫書.zip`；v7保存五份原始附件，v8為修訂成果。repo分類名稱沿用 **09_計劃書**，來源ZIP仍保留原名、原包內路徑與位元組。

- [00_檔名對照表.txt](00_檔名對照表.txt)：原附歷史命名表，保留在本層供各版本共用。其「v4為目前最新版」為當時敘述；目前最新工作稿為v8。
- [FILE_INVENTORY.csv](../FILE_INVENTORY.csv)：現行repo路徑、原始來源、ZIP包內路徑、大小與SHA-256；`archive_entry`保留來源包的歷史路徑。
- [HANDOFF_INVENTORY.csv](../../HANDOFF_INVENTORY.csv)：repo原始資料總清單與實際格式。
- [原始壓縮檔](../_原始壓縮檔/README.md)：保留來源ZIP以供核對。

## 如何接續使用

先讀[v8與CM03](v8/README.md)及人工核對清單，再依需求回查v1～v7。Word供編輯，PDF供閱讀；正式採用與送件版本由計畫負責人確認。這些文件是研究構想與申請草稿，日期取自檔名，不能用來證明正式提交日期或實驗已完成。

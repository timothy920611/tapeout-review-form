# 計劃書版本交接

資料由提供者上傳的 `09_計畫書.zip` 展開。依提供者更正，repo內資料夾統一命名為 **09_計劃書**；原ZIP、包內檔名與原附對照表不改寫，來源清單同時保留原包路徑。截圖的11號分類不另建副本。

內容是116年度國科會計畫申請工作稿，主題從FinFET SAR ADC巨集佈局，演進至4nm寄生感知多代理佈局與驗證平台。這些是計畫構想與申請草稿，不是已完成實驗或已核定計畫的證據。

## 如何接續使用

先讀v6與CM03，再依需求回查v1–v5；實際採用版本仍由計畫負責人確認。`00_檔名對照表.txt`保留原檔名與時間，但其「v4為目前最新版」敘述早於現有v5／v6，不應作為最新狀態。日期取自原檔名，不能用來證明正式提交日期。

Word可編輯、PDF供閱讀；部分主持人、學門與時程欄位仍為待確認內容。請另存工作副本後修改，不覆寫原稿。完整來源與SHA-256見 [FILE_INVENTORY.csv](../FILE_INVENTORY.csv)。

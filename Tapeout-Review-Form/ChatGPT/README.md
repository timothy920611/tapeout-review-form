# ChatGPT 審查表文件

本目錄的 Tapeout Review Form 由 ChatGPT 依上傳論文生成，製作時要求正確版與刻意含錯誤版，每款 AI 約 9–10 組案例。完整步驟見 [審查表生成流程](../README.md#生成流程)。資料提供者已補充製作流程；完整生成對話、提示詞與確切模型版本尚未附齊。

## 檔案內容

檔名含 `test` 或 `answer` 及案例編號，保留原始命名。正文包含電路規格、模擬條件、power line、DRC／LVS 等項目。請核對正文的專題名稱、Top Cell 與版本描述；正確／錯誤版是生成時的要求，`test`／`answer` 與內容的實際對應仍應逐份核對，不能僅以名稱當作人工驗證結果。

## 如何使用

先查 [根目錄檔案清單](../../HANDOFF_INVENTORY.csv) 確認實際格式，再用 PDF 閱讀器或 Word／LibreOffice 開啟。需要更正副檔名時，先複製到 repo 外再處理，避免改動原始備份。AppleDouble 檔不含可直接開啟的審查表正文。

這次已依實際格式完成 PDF 文字擷取與 DOCX XML 可讀性檢查；沒有重新驗證文件所聲稱的模擬、製程、性能或驗證通過結果。比較不同版本時，以內容為準，不假設與其他模型相同編號是一對一配對。

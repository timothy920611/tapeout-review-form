# Claude 審查表文件

這裡是既有 repo 依 `Claude` 名稱分組的 Tapeout Review Form，供閱讀與比較審查表填寫內容。來源分類以資料夾、檔名與文件正文為依據，尚未附完整產生對話、提示詞、模型版本、作者與年份紀錄。

## 檔案內容

檔名含 `test` 或 `answer` 及案例編號，保留原始命名。正文包含電路規格、模擬條件、power line、DRC／LVS 等項目。請核對正文的專題名稱、Top Cell 與版本描述；檔名中的 `answer` 不代表已經過人工驗證，`test` 的評分／測試定義也尚未完整記錄。

## 如何使用

先查 [根目錄檔案清單](../../HANDOFF_INVENTORY.csv) 確認實際格式，再用 PDF 閱讀器或 Word／LibreOffice 開啟。需要更正副檔名時，先複製到 repo 外再處理，避免改動原始備份。AppleDouble 檔不含可直接開啟的審查表正文。

這次已依實際格式完成 PDF 文字擷取與 DOCX XML 可讀性檢查；沒有重新驗證文件所聲稱的模擬、製程、性能或驗證通過結果。比較不同版本時，以內容為準，不假設與其他模型相同編號是一對一配對。
